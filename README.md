# Five Engines

Ontario betting intelligence built from **five genuinely independent pricing
engines** — Pinnacle, Kambi, Entain, Altenar and NEO.

Most "consensus" products average sportsbooks. Ontario's 35 books rent their
odds from a handful of trading desks, so averaging books counts one desk's
opinion many times over. We measured which books are actually independent and
build consensus from the engines instead.

`index.html` is generated from live data. `proof.md` is the rolling proof report,
which reports what the system **rejected** as prominently as what it found.

Nothing here is betting advice.
